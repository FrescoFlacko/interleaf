Read. Think. Build.

Interleaf is a reader for the books and papers you learn from. Highlight in five colours, write in the margins, and — only if you connect one — ask an AI about the page or hand a passage to a coding agent. Your library, notes and conversations are stored on your computer.

01

Library

One shelf for every format.

Import files, drag them in, or save a public web article as a Markdown snapshot with its still images archived locally. Keep a managed copy, or link a file in place and Interleaf will flag it as missing or changed if it moves.

  • Saved views: All Documents, Continue Reading, Recently Added, Recently Read
  • Nested folders, metadata filtering, sorting, grid and list views
  • Duplicates recognised by a SHA-256 hash of the file's content
  • Guided first-run setup — reading needs no account and no AI

02

Reading

A page that suits your eyes, and your hour.

Six reading palettes — Paper, Sepia, Moss, Ocean, Graphite and Midnight. Reflowable books take your line spacing, margins, font size and font family, including an OpenDyslexic-compatible option. PDFs zoom from 50% to 300% or fit the width or page. Interleaf remembers where you stopped.

03

Highlights & notes

Marginalia that stays put.

Select a passage and highlight it in Yellow, Blue, Green, Pink or Purple — each swatch is named, so colour is never the only cue. Attach a note to the passage or to your current location, and drop bookmarks as you go.

  • An Annotations browser with search, filters for highlights, notes and bookmarks, and sorting
  • Jump from any annotation straight back to its place
  • Highlights in reflowable books are anchored several ways, so they survive a change of layout

04

Search

Find the passage, not just the page.

Full-text search runs over an index of the open document and lists the matching passages. Pick a result and the reader goes there. Open it from anywhere with ⌘ F.

Scanned, image-only PDFs have no text to search; Interleaf does not run OCR.

05

Reader Chat · optional

Ask the page. Check the source.

With a provider connected, ask about a selection, a PDF page range, the whole document or one of your notes. Answers cite what you attached as clickable chips that jump to the passage; a citation the model invents stays plain text, so you can tell the difference.

  • A context-window meter, and Clean Context to compact a long conversation
  • Conversation history per document; save any answer as a note
  • Hosted web search when you use OpenRouter
  • Unsafe links in answers are rendered inert

06

Agent Mode · optional

From the book to a working build.

Send a passage, a PDF page range or the whole document to a coding-agent command-line tool you have installed, with a task and a working folder. By default the run happens in an isolated Git worktree or folder copy; you review the changed files and diff, then apply it, export a patch, or discard it.

  • Watch the run, stop it, and resume a session later
  • Modes that write directly to your folder ask for confirmation first

Isolation changes where the agent starts and where its ordinary work lands. It is not a container or an operating-system sandbox: the tool runs as your user account. Run agent tools you trust.

Where your data lives

Stored locally. Online only for what you ask.

Two different things, stated separately — because “private” is a claim worth being precise about.

Kept on your computer

  • Your library, managed copies, highlights, notes, bookmarks, conversations, settings and search indexes, in Interleaf's application-data folder
  • No account, and no sync — reading and annotating work without any AI
  • An OpenRouter key is encrypted with Electron safeStorage, backed by the operating system's keychain
  • Diagnostic logs are bounded and redacted, and exclude document text, prompts and credentials

When Interleaf goes online

  • Document and prompt text go to an AI provider only when you send a chat message or start an agent run with it
  • Detecting providers and checking sign-in runs the installed tools, and some of those contact their vendor
  • Listing a local server's models contacts that server; Interleaf only connects to a loopback address, but the server may forward requests elsewhere
  • Saving a web article fetches the page you gave it
  • Each command-line tool you install is its own program, with its own network behaviour
  • The macOS app and the Linux AppImage check Interleaf's public GitHub releases for a signed update. An update downloads only when you click Download, and you can turn checks off in Settings ▸ About & Updates

Bring your own AI

Use the tools you already have.

Interleaf does not sell or bundle model access. It works with command-line tools you have signed in to, an OpenRouter key, or a server on your own machine. All of it is optional.

By design

What Interleaf doesn't do.

  • No DRM removal

    DRM-protected EPUB and Kindle books are detected and refused.

  • No editing

    Your PDF, EPUB or Word file is never modified. Annotations live alongside it.

  • No embedded media

    Audio, video, embedded apps, forms and scripts inside documents are not played or run.

  • No OCR

    Scanned, image-only PDFs display, but have no text to select or search.
